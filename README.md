A short, funny rant about an everyday annoyance — a fitted sheet that goes
into the dryer as a sheet and comes out as a wet bag swallowing all the
other laundry — for the
[Angry Judge: The Short Rant Contest](https://make.fun/bounty/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046)
on make.fun.

## How it works

`main.ts` writes one 190-character rant to `/output/entry.txt`. Run it with
no arguments:

```sh
node main.ts
```

## Entry

> Why does a fitted sheet go into the dryer as a sheet and come out as a wet bag containing all my other laundry? The dryer says the load is dry because apparently it only interviewed the bag.
